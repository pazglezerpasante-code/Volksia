WOLSKIA Studio

Requisito: Node.js 22 (https://nodejs.org). Marque "Add to PATH".

Windows
1. Descomprima esta carpeta.
2. Doble clic en INICIAR.bat
3. Espere a que diga "ready" y use http://127.0.0.1:8080

Si aparece "spawn vite ENOENT":
  1. Abra CMD en esta carpeta
  2. rmdir /s /q node_modules
  3. npm install
  4. npm run dev

Mac o Linux
  npm install
  npm run dev
