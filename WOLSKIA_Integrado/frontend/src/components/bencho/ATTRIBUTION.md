# Bencho components

Source: component exports supplied by the user from [bencho.dev](https://bencho.dev/).
The supplied exports identify the component code as MIT licensed and link to [the licence page](https://bencho.dev/licence). Original explanatory comments have been preserved. This attribution is not a substitute for the full upstream licence notice.

Adaptations for Volksia: Spanish interface labels, local theme aliases, accessible focus/keyboard handling, callbacks for actual creation and sample confirmations, generic controlled input, and safe original SVG marks replacing the excluded Magnetic select images.

The original Bencho pictures are not included. The gallery was removed: interactions now serve actual task filters/counts, note fields, saved-operation notifications, file drops, local microphone recordings and confirmations. Asset swap’s two-slab expanding form is adapted to creating a task from a note; no financial widget is exposed.
