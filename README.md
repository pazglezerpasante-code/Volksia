# Wolskia

Asistente con IA para pasantes: chat, herramientas y «Tu espacio» (tareas, notas y agenda).

- **Frontend:** `WOLSKIA_Integrado/frontend` (React + TanStack Start) → se publica en Vercel.
- **Backend:** `WOLSKIA_Integrado/backend` (Python/Flask) → se publica en Render.
- **Sin login.** Cada navegador tiene su propio espacio (identificador guardado en el navegador).

## Probar en tu PC
Doble clic en `WOLSKIA_Integrado/INICIAR_TODO.bat` (necesita Node 22 y Python 3.10+).

## Publicarlo online
Seguir `WOLSKIA_Integrado/DEPLOY_ONLINE.md`.
